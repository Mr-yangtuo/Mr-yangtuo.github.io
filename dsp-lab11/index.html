为什么加窗能设计滤波器？

理想低通在频域是矩形，逆变换得到无限长的 sinc。直接实现需要无限多个系数，而且延伸到负时间。先平移，再截取并加窗，得到有限个可实现的系数。时域相乘对应频域卷积，因此理想的陡峭边缘被抹宽，通阻带产生波纹。

h[n] = hd[n] w[n]
hd[n] = sin(ωc(n−α)) / (π(n−α))
hd[α] = ωc/π = 0.5

Kaiser 参数怎么算？

把阶数统一记为 M，可避免与课件窗长 N 混淆。用课件经验公式估计：

M ≈ (As−7.95)/(2.285Δω)，Δω=0.16π
30 dB：M≈19.198 → 20；长度 21
60 dB：M≈45.317 → 46；长度 47

当 21<As<50 时，β=0.5842(As−21)0.4+0.07886(As−21)，代入 30 得 2.1166；当 As>50 时，β=0.1102(As−8.7)，代入 60 得 5.6533。边界 50 dB 通常使用中间一支。

Kaiser 窗的表达式为 w[n]=I₀(β√(1−(2n/M−1)²))/I₀(β)，n=0…M；I₀ 是第一类零阶修正贝塞尔函数。kaiser(M+1,β) 负责计算，无需手动展开级数。MathWorks：Kaiser 窗与 β 公式 ↗

这些是设计起点，不是达标证明。原导出函数已固定 N 和 β，没有在运行时由 Rp、As 自动求阶。设计后必须用频响检查全通带与全阻带。

06 / 容易卡住的地方

把这些细节弄清楚

为什么 fft 要乘 2？为什么又不能全部乘 2？

实信号正负频率成共轭对，一条幅度 A 的正弦在双边归一化谱各占 A/2。只画正频率时乘 2 才恢复 A。直流只有一份；偶数长度的奈奎斯特点也没有独立的一对，所以两者不应翻倍。原代码省略了奈奎斯特点并整体乘 2，对本题无直流的理想输入影响小，但不是一般情形的完整写法。

P2 = abs(fft(x))/L;
P1 = P2(1:L/2+1);
P1(2:end-1) = 2*P1(2:end-1);
f1 = (0:L/2)*fs/L/1000;

这是偶数 L 的标准补充写法；end 表示该维度末尾下标，2:end−1 排除两端。

freqz 与 fft 到底有什么区别？

freqz 输入滤波器系数，返回系统“对不同频率放大/缩小多少”的复增益。fft 输入一段信号，回答这段信号“含有哪些频率、各有多大”。Y=HX 是频域关系，但这里的完整卷积、有限截取和零状态瞬态需要一致处理；不能把有限长度滤波输出的每个 FFT 点都简单当作理想稳态。

hamming 后面那个单引号为什么不能删？

hd 是 1×43，hamming(43) 是 43×1。转置后才能逐项对应。新版本 MATLAB 中直接把行与列用 .* 相乘会隐式扩展成 43×43 矩阵，而不是需要的一维系数；旧版本还可能报尺寸错误。纯转置也可写 .'，但原代码的实数窗使用 ' 没有区别。

线性相位是不是一条没有折返的相位直线？

实对称 FIR 的 H(ω)=e^(−jαω)A(ω)，A 是实函数。A>0 时相位为 −αω，A<0 时还差 π；主值角度也会按 2π 折返。在非零响应且符号固定的区间，群延迟为 α。可用 unwrap(angle(H)) 查看去掉 2π 折返的相位，但零点附近仍不能保证简单直线。

应该先运行哪个文件？缺函数时怎么办？

将五个 .m 文件放在同一当前文件夹。运行 task1 可完成题 1；运行 task2a 会调用 FIR30；运行 task2b 会调用 FIR60。FIR30/FIR60 是函数文件，不需要提前运行“保存变量”。本次在 MATLAB R2024b 与 Signal Processing Toolbox 环境验证；hamming、kaiser、fir1、freqz 和相应滤波器对象依赖信号处理功能。用 which FIR30 检查是否找到正确同名文件。

MATLAB 区分大小写；脚本 fs 与函数 Fs 都必须设为同一采样率。页面提供的原代码保留原样，讲解与补充验证代码单独标出。

Rp 与 As 为什么一个越小越好，一个越大越好？

Rp 是有用频段损失了多少，越小表示越完整地保留信号；As 是噪声频段被压低了多少，越大表示抑制越强。Rp≤1 dB 对应最低幅度增益至少 10^(−1/20)≈0.89125；As≥40 dB 对应最大阻带幅度增益不超过 0.01。

GUI 的 Apass 通常描述通带纹波约束，脚本的 Rp 则只算相对 0 dB 的最大衰减。若严格比较 GUI 通带纹波，还应计算 max(dbpass)−min(dbpass) 并明确采用的定义。

07 / 思考题详解

从代码回到原理

1. 对理想的滤波器加窗，会出现哪些现象？

理想冲激响应被截成有限长度，实际可以实现；频域矩形边缘变成过渡带，通带和阻带出现波纹，阻带不再处处为零。原因是 h=hd·w 对应 H=(Hd*W)/(2π)。矩形截断尤其容易在不连续点附近出现 Gibbs 振荡；增加长度主要压窄波纹影响的频率范围，并不让同一窗的典型旁瓣电平无限下降。

2. 不同窗函数的差异主要是什么？

主要比较主瓣宽度、旁瓣电平和旁瓣衰减速度。主瓣影响过渡带，旁瓣影响通阻带波纹。常用窗方法的典型最小阻带衰减：矩形约 21 dB、Bartlett 约 25 dB、Hann 约 44 dB、Hamming 约 53 dB、Blackman 约 74 dB。这些是滤波器设计估计值，不能与“窗频谱最高旁瓣电平”混为一谈。

本题取 Δω≈6.6π/N 估算 Hamming 长度。Kaiser 多一个连续可调参数 β，可以在旁瓣抑制和主瓣宽度之间调节。

3. 有没有一种窗函数阻带衰减又大、过渡带还窄？

在固定长度、相同比较条件下，课上这些常用窗存在折衷，不能无代价地兼得。增大 β 可压低旁瓣，但主瓣变宽；为了保持过渡带宽，需要同时增加长度。题 2 正好展示了这种代价：衰减目标从 30 提到 60 dB，长度从 21 增至 47，延迟从 1 ms 增至 2.3 ms。

所以回答“没有”需要加上“在相同长度等条件下”的前提；允许增加阶数时，就可以在更窄过渡带和更高衰减之间取得更好的组合，代价是计算量与延迟。
